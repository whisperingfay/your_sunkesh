STATUS & INFOS
- git status (kung nasaang repository or branch)
- git log (tingnan ang history ng commits)
- git log eto mga commits tapos pang gamit sa revert
- git revert 
- git branch (makikita lahat ng branch)

ADDING & COMMITING
- git add . (i-stage lahat ng changes sa folder, . meaning lahat)
- git add <file> (i-stage ang file para sa commit, specific lang ipu-push)
- git commit -m "message" (i-save ang staged changes sa local repo)

PUSH & PULL
- git push (i-upload ang commits sa remote branch)
- git pull (kukunin lahat yung bagong commits galing github at magmerge sa local mo)

BRANCHING & MERGING
- git branch <name> (Gumawa ng bagong branch)
git checkout <name> or git switch <name> (Lumipat sa ibang branch)
